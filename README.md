# Desenvolvedor Back-End - Turma 176A.DBKE.2N26
Repositório com as atividades desenvolvidas no curso do **SENAI de Americana** para qualificação em 
**Desenvolvimento Back-End**.
## 🎯 Objetivo do curso 🎯
O curso de Qualificação Profissional de Desenvolvedor Back-End tem por objetivo o desenvolvimento 
de competências que permitem projetar, desenvolver e manter sistemas e aplicativos na parte do 
servidor e seguindo boas práticas, procedimentos e normas.
